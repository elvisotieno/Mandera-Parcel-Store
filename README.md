# Mandera Parcel Store

Single-file web app for parcel intake, dispatch, issue, tracking, and reporting.

## Live Testing (GitHub Pages)

After deployment, testers can open the site URL and use the demo logins below.

## Demo Accounts

- staff1 / staff123
- supervisor1 / super123
- admin / admin123

## Local Run

1. Open index.html in any modern browser.
2. Sign in using one of the demo accounts.

## Notes

- Data is stored in browser localStorage.
- Barcode rendering uses JsBarcode from CDNJS.
- This is a demo app with frontend-only authentication.

## Deploy To GitHub Pages

1. Push this project to the main branch.
2. In GitHub: Settings > Pages.
3. Source: Deploy from a branch.
4. Branch: main, Folder: /(root).
5. Save and wait for the Pages URL.
